Featured Academic Project

Community Food Platform

A detailed look at why I developed the project, how I approached the problem, the technology behind it, and the social impact I wanted the system to support.

Socially Focused Computing Project
Community-Based Food Ordering and Delivery Platform with Surplus Food Redistribution

This project was developed as my final-year Computing Science project at Ulster University. Instead of treating food delivery as only a commercial transaction, I explored how the same digital infrastructure could also help restaurants redirect suitable surplus food through NGOs and community organisations.

COM668 Computing Project 2024/2025 Full-stack system Spring Boot + React + MySQL
Why I developed it

I wanted to explore a practical technology problem with a clear human dimension: food ordering is increasingly digital, while surplus food and food insecurity remain community challenges. My idea was to connect these two areas rather than build another ordering system focused only on transactions.

How the idea works

The platform brings together customers, restaurants, delivery personnel and NGOs. Customers can browse restaurants and place orders; restaurants can manage menus and orders; delivery personnel can support delivery workflows; and NGOs can coordinate surplus-food collection.

Social impact

The donation workflow was designed to help reduce avoidable food waste and create a structured route for suitable surplus food to reach organisations supporting people in need. The project therefore connects software engineering with sustainability, food redistribution and community support.

Community service & hunger

The social side of the project reflects my wider interest in community service and the human impact of access to food. I wanted the technology to address more than convenience by considering hunger, food insecurity and how local organisations can work together more efficiently.

Technology Used
From interface to database

The system was designed as a layered full-stack application with separate presentation, business-logic, security and data responsibilities.

React.jsJavaScriptHTML / CSSSpring BootJavaREST APIsMySQLSpring Data JPASpring SecurityGoogle Maps APIPayPalTwilioGit / GitHubJest
Security and privacy were considered through authentication, authorisation and data-protection measures documented in the project.
System Design
How I built it

The back end followed an MVC/layered approach separating controllers, services, repositories, security and configuration. React handled the user-facing experience while Spring Boot exposed the application logic through RESTful APIs and MySQL stored users, restaurants, orders and donation-related data.

  • Responsive React front end and REST API communication
  • Spring Boot business logic and layered architecture
  • MySQL relational database with JPA
  • Google Maps integration for location and delivery workflows
  • PayPal integration for online payments
  • NGO donation workflow for surplus-food redistribution
Development Approach
Agile, iterative and feedback-driven

I developed the platform through structured planning, Kanban tracking and Agile sprint cycles. Stakeholder feedback and testing were used to refine the system rather than treating the original design as fixed.

  • Requirements and user stories
  • Work-breakdown structure and Kanban tracking
  • Incremental feature development
  • Risk assessment and mitigation planning
  • Iterative refinement from stakeholder feedback
Testing & Validation
Built, tested and reviewed

Testing was part of the development process rather than an afterthought. The project included functional testing, system testing, front-end unit testing and stakeholder-based user acceptance testing.

  • React/Jest component tests were used for front-end validation
  • System and functional requirements were tested against project milestones
  • User acceptance testing gathered feedback from restaurant stakeholders
  • Performance issues identified through feedback were addressed during later development cycles
What I Learned
Engineering beyond writing code

The project strengthened my experience in turning a real-world problem into requirements, designing a multi-user system, integrating external services, testing software, responding to feedback and considering security, accessibility, scalability and social responsibility together.
